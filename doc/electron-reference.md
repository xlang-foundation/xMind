# Electron scope boundary

The standalone Electron IDE is excluded from xMind OSS as of the 2026-10-07 scope revision. It belongs to CantorAI’s closed-source Nexus project. The previous CantorAI/WorkSense runtime investigation was moved to that separate local workspace. No standalone Electron implementation was found in xMind. Existing installed applications and sibling projects are preserved.

OSS clients remain the native CLI, browser UI and VS Code extension. See the [OSS specification](architecture.md).
