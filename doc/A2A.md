# Native A2A integration

A2A handling belongs to the C++ backend. The earlier Python adapters and their probes were removed; Git history preserves their development record.

Current implementation and verification limits:

- [Task inspection and cancellation](../doc/native-a2a-task-control.md).
- [Message admission and replay](../doc/native-a2a-message-admission.md).
- [Streaming and observation](../doc/native-a2a-streaming.md).
- [Versioned A2A adapter](../doc/native-a2a-v1.md).

These component contracts do not establish complete A2A compliance or all remote-agent capabilities.
