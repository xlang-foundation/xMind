# Native graph execution component

The native backend now owns queued/running/paused graph roots and exposes authenticated HTTP and CLI catalog, admission, detail, child/event, human-input and cancellation controls. See [graph service commands and lifecycle](native-graph-service.md). Local compiled validation passed **44 native contracts**, including actual file reads, approved writes, restart, pause ownership, input races and a real effect-journal failure. Provider replies/counts are synthetic protocol fixtures; VS Code graph workflows and live-provider graph acceptance remain pending. Source/binary verification belongs in the graph-service evidence files.

Partial human input leaves the root paused when only unanswered human nodes remain, without emitting a false running/pause pair. Input that makes a branch runnable resumes that actual work. Repository and runner contracts cover rollback, restart, final-input resume, and an independent branch released by the first answer. Checkpoint `d533ffe8d675d2f8ac04421cec97c05e846aa60e` passed the earlier full **43 native / 48 extension** suite in [CI](https://github.com/xlang-foundation/xMind/actions/runs/37673932355), including idle HTTP fairness without longer client deadlines. Its predecessor `6a442adf8bfa3c1e1702c23afcd91bb4e34e0a6b` failed **42/43** with a concurrent HTTP timeout; the [original failed job](evidence/native-cli-graph-partial-wait-failed-ci-job.log) remains preserved. The installed preview remains on its verified discovery backend with the latest sidebar adapter.

The C++ `GraphRunner` executes immutable backend graph plans through the native agent engine and workspace/effect handlers. Its earlier component checkpoint `77ffa610661abdab910b270e086c1bedf9f2a325` passed **41 native and 41 extension contracts** in [isolated CI](https://github.com/xlang-foundation/xMind/actions/runs/37655834894): [hosted CTest](evidence/native-graph-runner-hosted-ctest.log), [original job/TAP](evidence/native-graph-runner-passing-ci-job.log), [hosted provenance](evidence/native-graph-runner-hosted-provenance.json). Earlier [local build output](evidence/native-graph-runner-local-build-ctest.log) and [provenance](evidence/native-graph-runner-local-provenance.json) retain their original component scope. Offline catalog import itself does not execute graphs; the running service reports actual capability through `/v1/graphs`.

Schema version 7 retains each new graph's original task/model input alongside its immutable specification. Legacy roots have an explicitly unavailable input, rather than a guessed prompt reconstructed from session history. Child conversations remain isolated from siblings and root history. Tool children cannot invoke the model engine, and single-agent workers cannot claim graph roots.

The controller admits ready agent/tool nodes with the stored checkpoint revision, runs at most 1–8 workers (default 2), settles actual terminal children from durable records, resolves typed dependency arguments and commits conditional skips. Human steps pause durably after all other runnable branches retire, including a human wait admitted concurrently with executable work. Resume consumes authenticated controller input; completed branches are not replayed. The final root response contains observed node outputs and states, with `source: graph_join`. It does not invent aggregate provider usage.

Direct tools use registered native workspace reads and, when enabled, the existing approved edit/create/process executors. File/command effects retain separate one-use approvals, exact proposals, guidance snapshot preconditions and existing journal/recovery rules. Configured agent nodes retain their model/tool loop, including registered MCP tools. Direct MCP graph-tool aliases remain unsupported.

Cancellation stops and joins owned children before root retirement. Failed effects/children halt later admission. Missing dependency paths retire the root as a data-resolution failure; they do not supply invented values. A persistence fault requests cancellation of other workers and preserves the original fault and unfinished journal for recovery. An effect whose outcome cannot be journaled stays unrecorded/uncertain, even when its actual file bytes exist.

The compiled integration contract uses synthetic provider replies over actual native HTTP transport. It exercises concurrent agent requests, actual file reads, durable human pause/resume, typed references, conditional skips, observed joins, missing files/reference data, cancellation, actual separately approved file creation, cancellation during approval, and an injected SQLite outcome-journal failure followed by recovery without replay. The fixture values are test data, not a live model acceptance result.

The executor currently applies a deadline to each active segment, excluding returned human pauses. A persisted total graph budget, large result artifacts, loop/script nodes, combined scheduling budget and complete editor graph integration remain required.
